Removes bookmarks on X

This is not a local reset. Removed posts disappear from your X bookmarks on every device. Your captured export is kept. There is no automatic undo.

Before you start
  1. Capture and export your bookmarks first if you want an independent copy.
  2. Open x.com/i/bookmarks in the signed-in account you want to clear. Keep that tab open.
  3. Start and confirm. Pause or stop at any time; the in-flight request finishes before the checkpoint is saved.
  4. Download Backup JSON to review removed posts. It preserves post data and links, not downloaded media files.
Pacing, verification & recovery

Uses X's own bookmark responses and DeleteBookmark operation, with the same warm-up, jittered gaps, wave breaks, rate governor and backoff as Unfollow. Re-reads the live feed after removals so a shrinking list cannot skip posts. Completion requires two empty live-head checks. X may withhold older or unavailable entries; completion only describes what its API returned.

Every run checkpoints after 2,500 attempts or 3 hours. Resume is tied to the same account. Capture, Unfollow and Unsave cannot run together, even in different tabs.
