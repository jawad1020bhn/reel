Removes bookmarks on X

This is not a local reset. Removed posts disappear from your X bookmarks on every device. Your captured export is kept. There is no automatic undo.

Before you start
  1. Capture and export your bookmarks first if you want an independent copy.
  2. Open x.com/i/bookmarks in the signed-in account you want to clear. Keep that tab open.
  3. Start and confirm. Pause or stop at any time; the in-flight request finishes before the checkpoint is saved.
  4. Download Backup JSON to review removed posts. It preserves post data and links, not downloaded media files.
Pacing, verification & recovery

Uses X's own bookmark responses and DeleteBookmark operation, with the same warm-up, jittered gaps, wave breaks, rate governor and backoff as Unfollow. Re-reads the live feed after removals so a shrinking list cannot skip posts. Completion requires two empty live-head checks. X may withhold older or unavailable entries; completion only describes what its API returned.

Every run checkpoints after 2,500 attempts or 3 hours. Resume is tied to the same account. Capture, Unfollow and Unsave cannot run together, even in different tabs.

    Removes saved posts on Reddit

    This is not a local reset. Unsaved posts leave your Reddit saved list on every device. Your captured Reddit library is kept. There is no automatic undo — only the backup.

    Before you start
    1. Run Capture and Export first if you want an archive with playable video URLs. The backup keeps post data and links only.
    2. Stay logged in on old.reddit.com with I am over eighteen enabled, and open old.reddit.com/user/<you>/saved in this tab. Keep it open.
    3. Start and confirm. Pause or stop at any time; the in-flight request finishes before the checkpoint is saved.
    4. Download Backup JSON afterwards. It imports into XReels like a normal Reddit export.
    Pacing, verification & recovery

    Replays old.reddit's own unsave request with your session's modhash, so nothing is sent without Reddit's CSRF token. Same warm-up, jittered gaps, wave breaks, rate governor and backoff as the X engines, tuned to ~14/min for Reddit's tighter web limits. Only Reddit's explicit success counts as removed; HTML, errors and unknown replies keep the post queued and stop for review.

    Removing posts shifts Reddit's pagination, so the live list is re-read from the top after every batch. Completion needs two clean sweeps of the whole list plus a final session check (logged in, same account, NSFW visible). A post Reddit keeps listing after a confirmed removal is retried once, then the run pauses instead of claiming completion. Each run checkpoints after 1,500 attempts or 3 hours; resume is tied to the same account.
